## 추가 데이터 또는 운영 요구사항이 필요한 다음 단계

1. 기존 SECOM과 독립된 신규 시간대 데이터 검증. 실제 Lot·설비 키 확보 시 그룹 분할.
2. 현장 검사 처리 용량 및 FN/FP 비용을 받은 뒤 임계값 정책 검증.
3. 별도 검증 데이터에서 확률 보정 및 불확실성 분석.
4. 공정 feature 의미 매핑과 원인 후보의 엔지니어 검토.
5. 인증, 멱등키, migration 관리, 모델 승격·롤백, drift 감시, 변경 감사 로그 추가.

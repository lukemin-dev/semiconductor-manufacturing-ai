# 개선 계획 - 2026-09-20

## 문제와 실행 순서

1. **선정 안정성**: 현재 단일 validation 26개 Fail에 의존하여 선택한 Logistic 모델이 test에서 낮은 AP를 보였다. 기존 결과를 experiments/v1에 보존하고, 기존 train+validation 영역 1,175개만 사용하는 반복 층화 5-fold × 3회 교차검증으로 선택한다. 결측·상수 필터와 feature 선택을 fold 안에서 다시 학습한다.
2. **고차원 과적합**: 442개 입력과 작은 불량 표본의 비율을 고려해 ANOVA top-40 feature 선택 및 더 강한 Logistic 정규화를 사전에 비교 후보로 추가한다. RF/XGBoost/IsolationForest와 같은 데이터 분할을 사용한다.
3. **오경보 부담**: 기존 F2 최대 임계값이 대량 경보를 만들 수 있다. OOF 예측에서 경보 비율 상한 30%를 적용하는 시연 정책을 추가하고, 제한 안에서 F2를 최대화한다. 현장 비용에 기반한 값이 아님을 명시하고 CLI에서 변경 가능하게 한다.
4. **검증 근거**: fold별 AP, 모델별 평균/표준편차, OOF predictions, feature 선택 빈도, split 감사 기록 및 테스트 bootstrap 구간을 저장한다. 동일 테스트의 전후 비교는 이미 공개된 holdout을 재사용한 탐색 결과임을 명시한다.
5. **코드 품질**: 전처리를 sklearn estimator로 만들어 CV와 추론에서 공유한다. 임계값 정책·fold 분리·입력 오류·DB 저장·대시보드 동작을 테스트한다. 자동 포맷과 CI를 보강한다.
6. **GitHub 정리**: 기술 README, 실행 예시, 아키텍처, 테스트, 재현 가능한 결과 및 라이선스/출처를 배치한다. 개인 지원서·경력 연결 문서는 로컬 배포 ZIP에만 보관한다. 계정과 공개 범위 확인 후 저장소를 생성하고 CI를 확인한다.

## 평가 원칙

- 새 비교 후보와 정책은 v2 test 평가 전에 이 문서와 코드로 고정한다.
- v1 test는 이미 확인했다. v2 성능을 독립된 신규 검증 또는 현장 성능으로 주장하지 않는다.
- 모델은 development CV 평균 AP로 선택한다. 테스트가 낮아도 다시 선택하지 않는다.
- bootstrap 구간은 고정 모델·고정 테스트 샘플에 대한 조건부 추정이며 학습 및 모델 선택 불확실성을 모두 포함하지 않는다.
- 시간순 신규 holdout 확보와 실제 공정 키 기반 검증은 후속 과제로 남긴다.

## 실행 결과

- 120개 fold 학습 완료. Random Forest balanced 선정: CV AP 0.210 ± 0.080.
- 기존 test: Recall 0.692, Precision 0.180, F1 0.286, AP 0.244. v1 대비 개선됐으나 재사용 holdout임.
- 시간순 민감도 분석: Recall 0.412, AP 0.082. 현장 적용 가능성을 결론 내리지 않음.
- 경보 확인 처리 API/UI, 분할·임계값 테스트 및 Ruff 검사 추가.
- 공개 GitHub에는 개인 지원서/경력 연결 문서를 제외함.

# 3분 시연 순서

1. README의 전후 결과와 시간순 결과를 함께 보여준다. v2 개선을 실제 수율 개선으로 설명하지 않는다.
2. Dashboard에서 모델 버전, test 지표, 분할 이름을 확인한다. 상단 지표는 선택한 샘플의 성능이 아니라 저장된 test 평가다.
3. Lot과 샘플을 선택해 예측을 저장한다. 위험 점수와 임계값, 결측 비율, TOP5의 양수·음수 의미를 설명한다.
4. 이력에 예측 ID와 모델 버전이 저장됐는지 확인한다. 경보 샘플에서는 확인 완료로 상태를 바꾸고 원래 예측은 변하지 않는지 보여준다.
5. artifacts/cv_summary.csv에서 top-40 feature 선택이 무조건 좋아지지 않았음을 보여준다.
6. temporal_metrics.json에서 시간순 성능 저하를 보여주고 새 데이터 검증 없이 배포를 결론 내리지 않은 이유를 설명한다.

면접에서 설명할 세 가지 결정: 테스트로 모델 재선정 금지 / fold 안에서 전처리 fit / 불량 누락과 오경보를 함께 평가.
